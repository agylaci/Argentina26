ARGENTINA 2026 — LOCAL DEMO

Mac / Linux:
1. Nyisd meg a Terminalt ebben a mappában.
2. Futtasd: ./start_mac_linux.sh
3. Nyisd meg: http://localhost:8000

Windows:
1. Dupla kattintás: start_windows.bat
2. Nyisd meg: http://localhost:8000

Alternatíva bármely rendszeren Python 3-mal:
python3 -m http.server 8000

Leállítás: Ctrl+C a terminálablakban.
